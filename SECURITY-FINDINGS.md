**OWASP A01:2021 — Broken Access Control — URL-based access control bypass (CWE-288)** Within A01 the specific pattern is bypassing access control by modifying the URL, which is listed as one of the named examples.
- What was found. The authentication middleware in pkg/registry/auth/auth.go matches skip-list entries against only the final segment of the request path. Four entries are single-segment — /health, /metrics, /ping, /docs — so any request ending in one of those segments skips authentication at any depth. **An unauthenticated caller can reach handlers by ending the URL in ping, docs, health, or metrics.**
- How it was confirmed. GET /v0/servers returns 401 with the plain-text body the middleware writes. GET /v0/servers/ping returns 404, meaning the middleware never ran. GET /v0/servers/nope/versions/ping returns 401 with a JSON body, meaning the middleware skipped but the database-layer check caught it.
- Current impact. Confirmed reachable. GET /v0/deployments/abc123 returns the middleware's plain-text Unauthorized at 401, while GET /v0/deployments/ping returns {"title":"Not Found","status":404,"detail":"Deployment not found"} — a handler-generated response, proving the request ran unauthenticated with nothing behind the middleware to stop it. On /v0/servers/{serverName}/versions/{version} the skip also fires, but the authorization check in postgres.go rejects the missing session and returns a JSON 401, so that route is contained. Containment is per-handler rather than systemic, and the deployments handler has no such check.
- Why it still matters. Containment is per-handler, not systemic, and the first handler tested had no check. Nine routes end in a caller-controlled parameter, so each needs to be checked individually: the three artifact version routes for servers, agents, and skills, the prompts version route, /v0/servers/{serverName}/readme, /v0/providers/{providerId}, /v0/embeddings/index/{jobId}, /v0/deployments/{id}, and the AR-2 reviews route. Only the servers version route is confirmed contained.
- Origin and fix. Upstream code (nothing Navteca did), duplicated in router.go and auth.go. The narrow fix is dropping the pathToMatch lookup so only full-path matches count, since every entry in both lists is already written as a complete path.
